== 문서 개요

이 문서는 Spring REST Docs 기반으로 생성된 Homerun 백엔드 API 문서입니다.

== 공통 규약

=== 성공 응답

JSON 기반 성공 응답은 `status`, `message`, `data` 구조의 `ApiResponse` 로 반환합니다.
이미지 다운로드처럼 바이너리 본문을 반환하는 API는 응답 헤더와 바이너리 바디를 직접 반환합니다.

=== 에러 응답

모든 에러 응답은 `code`, `message`, `errors` 구조의 `ErrorResponse` 로 반환합니다.
`errors` 는 검증 실패 상세 정보 또는 추가 에러 정보 목록이며, 없는 경우 빈 배열로 반환됩니다.

=== 인증

보호 API는 `Authorization: Bearer <access-token>` 헤더를 사용합니다.
