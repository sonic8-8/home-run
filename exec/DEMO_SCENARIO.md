# Homerun Demo Scenario

이 문서는 평가/시연에서 바로 따라갈 수 있는 핵심 해피패스 시나리오다.  
현재 프론트 라우트와 실제 버튼 문구 기준으로 작성했다.

기본 URL:

```text
https://j14c103.p.ssafy.io
```

## 1. 시연 전 준비

### 1.1 브라우저 준비

- 크롬 또는 엣지 최신 버전 사용
- 팝업 차단 해제 권장
- 인터넷 연결 확인

### 1.2 계정 준비

아래 둘 중 하나를 사용한다.

- 기존 데모 계정으로 로그인
- 신규 계정을 시연 중 직접 회원가입

신규 회원가입을 보여줄 경우, 자산 연동 3단계 화면까지 자연스럽게 이어진다.

## 2. 시연 시나리오

### 2.1 로그인 화면 진입

| 항목 | 내용 |
| --- | --- |
| URL | `/login` |
| 첫 화면 | 로고와 `이메일 로그인` 버튼만 보이는 온보딩 화면 |
| 설명 포인트 | 서비스 첫 진입은 단순한 로그인 진입 구조이며, 이후 회원가입 또는 로그인으로 분기된다. |

실행 순서:

1. 브라우저에서 `https://j14c103.p.ssafy.io/login` 접속
2. 가운데 `이메일 로그인` 버튼 클릭
3. 이메일/비밀번호 입력 폼으로 전환되는지 확인

### 2.2 회원가입 시연

로그인 대신 신규 흐름을 보여줄 경우:

1. 로그인 폼 하단의 `이메일로 회원가입하기` 클릭
2. 아래 항목 입력
   - 이름
   - 이메일
   - 비밀번호
   - 비밀번호 확인하기
3. `이용약관` 클릭 후 약관 모달을 열어 설명
4. 약관 동의 후 `회원가입` 버튼 클릭
5. 가입 완료 후 로그인 화면으로 돌아오는지 확인

설명 포인트:

- `비밀번호가 일치하지 않습니다.` 같은 프론트 검증 메시지를 보여줄 수 있다.
- 회원가입 완료 후 로그인 폼으로 복귀하는 흐름이 깔끔하다.

### 2.3 로그인 시연

1. 로그인 화면에서 이메일과 비밀번호 입력
2. `로그인` 버튼 클릭
3. 최초 자산 미연동 계정이면 자산 연동 3단계 화면으로 이동
4. 기존 연동 계정이면 홈 대시보드로 바로 이동

## 3. 자산 연동 3단계

자산 미연동 사용자 기준으로 시연한다.

### 3.1 1단계: 기본 정보

화면 설명:

- 상단 step indicator 에 `기본 정보`, `금융 자산`, `카드 지출` 이 보인다.
- 입력 항목:
  - `주 계좌 잔액 (원)`
  - `월급 입금일`
  - `월 급여 (원)`
  - `월 고정지출 (원)`
  - `직업 유형`

실행 순서:

1. `주 계좌 잔액` 입력
2. `월급 입금일` 입력
3. `월 급여` 입력
4. `월 고정지출` 입력
5. `직업 유형` 선택
6. 다음 단계 버튼 클릭

### 3.2 2단계: 금융 자산

화면 설명:

- `보유 금융 자산 정보를 입력해 주세요` 문구가 보인다.
- 예금, 대출, 기타 수입 항목을 필요하면 추가할 수 있다.

실행 순서:

1. 예금 항목 1개 정도 추가
2. 필요 시 대출 또는 기타 수입 항목 1개 추가
3. 다음 단계 버튼 클릭

설명 포인트:

- 실제 서비스에서는 보유 금융 자산을 구조화해서 입력받는다.
- 시연에서는 1개씩만 입력해도 충분하다.

### 3.3 3단계: 카드 지출

화면 설명:

- `카드 지출 및 결제 유형을 설정해 주세요` 문구가 보인다.
- 최대 3개 카테고리를 선택할 수 있다.

실행 순서:

1. 카드 지출 항목 1~2개 입력
2. 주요 결제 카테고리 1개 이상 선택
3. 제출 버튼 클릭
4. 정상 완료 시 홈 화면으로 이동

## 4. 홈 대시보드 시연

홈 화면에서는 아래를 순서대로 보여주면 안정적이다.

1. 상단 요약 카드
2. PASS 위젯
3. 대출 추천
4. 카드 추천
5. 시드머니 위젯
6. `GAME START` 배너
7. 신용점수 위젯

설명 포인트:

- 금융 대시보드와 게임 진입이 한 화면에서 자연스럽게 연결된다.
- 사용자는 금융 상태를 확인한 뒤 게임으로 들어간다.

## 5. 게임 시작 시연

### 5.1 게임 시작 화면

URL:

```text
/game/start
```

버튼:

- `이어하기`
- `새로하기`
- `엔딩 저장소`
- 가이드 버튼

실행 순서:

1. 홈 화면 우측 `GAME START` 배너 클릭
2. 게임 시작 화면에서 `새로하기` 클릭

### 5.2 저장 슬롯

설명 포인트:

- 빈 슬롯은 새 게임 시작
- 진행 중 슬롯은 이어하기

실행 순서:

1. `빈 슬롯 - 새 게임 시작` 또는 빈 슬롯 카드 클릭
2. 캐릭터 선택 화면으로 이동하는지 확인

### 5.3 캐릭터 선택

실행 순서:

1. 남/여 캐릭터 중 하나 클릭
2. 오른쪽 `NEXT` 버튼 클릭

### 5.4 닉네임 입력

실행 순서:

1. `닉네임을 입력해주세요.` 입력창에 닉네임 입력
2. `NEXT >` 버튼 클릭

### 5.5 시작 방법 선택

버튼:

- `자산 연결해서 시작하기`
- `직업 선택하기`

평가 시연 권장 경로:

- `직업 선택하기`

이유:

- 현재 해피패스에서는 가장 예측 가능하고 빠르게 다음 단계로 이어진다.

실행 순서:

1. `직업 선택하기` 선택
2. `NEXT >` 클릭

### 5.6 직업 선택

설명 포인트:

- 카드 형태로 직업 능력치가 보인다.
- `START` 버튼으로 확정한다.

실행 순서:

1. 좌우 화살표로 직업 카드 넘기기
2. 원하는 직업에서 `START` 클릭

## 6. 목표 지역/매물 선택

직업 선택 후 부동산 화면으로 이동한다.

### 6.1 지역 선택

화면 우측 상단 안내 카드 문구:

- `지역을 먼저 고르세요`
- `시작할 광역시·도를 고르면 실제 매물 지도까지 자연스럽게 좁혀집니다.`

실행 순서:

1. 대한민국 지도에서 광역시/도 하나 클릭
2. 다음 화면에서 구/군 하나 클릭

### 6.2 매물 선택

설명 포인트:

- 상세 패널에서 가격, 주소, 면적 등을 확인할 수 있다.
- 새 게임 흐름에서는 `이 매물로 시작하기` 버튼이 보인다.

실행 순서:

1. 지도 마커 또는 매물 카드 선택
2. 왼쪽 상세 패널에서 `이 매물로 시작하기` 클릭

## 7. 게임 메인 진입

매물 선택이 끝나면 게임 메인으로 이동한다.

보여줄 요소:

- 현재 캐릭터와 상태
- 뉴스 진입 버튼
- 주식, 대출, 카드, 부동산 메뉴
- 이번 달 행동 선택 흐름

설명 포인트:

- 금융 의사결정과 게임 루프가 결합된 핵심 화면이다.
- 여기서부터 뉴스, 대출, 카드, 부동산, 이벤트를 반복하면서 턴을 진행한다.

## 8. 시연 시간 5분 기준 추천 순서

1. 로그인 화면 진입
2. 회원가입 또는 기존 계정 로그인
3. 자산 연동 3단계 빠르게 통과
4. 홈 대시보드 설명
5. `GAME START`
6. `새로하기`
7. 저장 슬롯
8. 캐릭터 선택
9. 닉네임 입력
10. `직업 선택하기`
11. 직업 카드에서 `START`
12. 지역/구 선택
13. `이 매물로 시작하기`
14. 게임 메인 도착 후 핵심 메뉴 설명

## 9. 시연 중 자주 쓰는 멘트

- "금융 정보 확인 뒤 바로 게임으로 넘어가는 구조입니다."
- "초기 온보딩은 캐릭터, 닉네임, 직업, 목표 매물 설정 순서입니다."
- "부동산은 실제 지도 흐름처럼 지역, 구, 매물 순으로 좁혀집니다."
- "게임 메인에서는 뉴스와 금융 의사결정을 매 턴 반복합니다."
