## 기획에 필요한 기술 정리

- **Backend (Spring Boot / JPA):**
    - 객체지향 설계(OOP)와 Strategy 패턴을 활용하여 조건부 대출, 이자 정산, 세금 계산 등 복잡한 도메인을 깔끔하게 분리.
    - TDD를 적용해 1턴마다 발생하는 복잡한 금융 시뮬레이션 로직을 결함 없이 처리.
    - **Redis:** 게임 중 수시로 변하는 세션 데이터를 인메모리로 빠르게 처리.
- **Frontend (React.js / TypeScript):**
    - **레트로 도트(Pixel Art)** 그래픽 UI/UX로 무거운 핀테크 느낌 탈피. 소비 통제 성공 시 방이 꾸며지는 시각적 애니메이션 구현.
- **AI Agent (Spring AI / LangChain):**
    - 최신 경제 뉴스를 RAG로 물려, AI가 매 판마다 새로운 거시 경제 이벤트를 생성. 정부의 부동산 정책 부분 활용 필요
- **활용 API (SSAFY 핀테크 오픈 API):**
    - `계좌/수시 입출금` (잔고 동기화 및 1원 송금), `카드` (소비 패턴 분석 및 가상 트랜잭션), `대출` (한도 및 금리 조회) 
- **부동산 API:**
    - 실거래하는 매물들은 불러와서 실제 원하는 매물을 목표로 할 수 있게 활용
