## 1. 네이버 지도 API 인증 (`ncpKeyId` vs `ncpClientId`)

### 문제
네이버 지도가 "인증 실패" 에러를 표시

### 원인
NCP **통합 계정**(개인/일반)에서는 파라미터명이 변경됨

| 이전 (구 버전) | 현재 (통합 계정) |
|---|---|
| `ncpClientId` | `ncpKeyId` |

### 해결
```html
<!-- index.html -->
<script src="https://oapi.map.naver.com/openapi/v3/maps.js?ncpKeyId=%VITE_NAVER_MAP_CLIENT_ID%"></script>
```

> [!TIP]
> Vite에서는 `%ENV_VAR%` 문법으로 HTML 내 환경변수를 치환할 수 있음

### 참고 문서
- [NCP 튜토리얼](https://navermaps.github.io/maps.js.ncp/docs/tutorial-2-Getting-Started.html)
- NCP 콘솔에서 **Web Service URL**에 `http://localhost` (포트 없이) 등록 필수

## 2. 네이버 지도 Data Layer — `naver.maps.Data`

### 핵심 개념
네이버 지도 [Map](file:///c:/Users/SSAFY/me/project/src/app/components/KoreaMap.tsx#518-688) 객체는 기본으로 `map.data`라는 [Data](file:///c:/Users/SSAFY/me/project/src/app/components/KoreaMap.tsx#735-828) 인스턴스를 포함하고 있음

### 주요 API
```js
// GeoJSON 데이터 추가
const features = map.data.addGeoJson(geojsonObject, false);

// 스타일 설정 (함수로 feature별 분기 가능)
map.data.setStyle((feature) => ({
  fillColor: "#FF3B30",
  fillOpacity: 0.25,
  strokeColor: "#FF3B30",
  strokeWeight: 2,
}));

// 특정 feature만 스타일 오버라이드 (hover 등)
map.data.overrideStyle(feature, { fillOpacity: 0.3 });
map.data.revertStyle(feature);  // 원래 스타일로 복원

// feature 삭제
map.data.removeFeature(feature);

// 이벤트 리스너
map.data.addListener("click", (e) => { /* e.feature, e.coord */ });
map.data.addListener("mouseover", (e) => { ... });
map.data.addListener("mouseout", (e) => { ... });

// feature 속성 접근
feature.getProperty("adm_nm"); // 행정동 이름
```

## 3. 행정동 경계 GeoJSON 데이터

### 데이터 소스
- **GitHub**: [vuski/admdongkor](https://github.com/vuski/admdongkor) — 대한민국 행정동 경계 GeoJSON
- 좌표계: WGS84 (EPSG:4326)
- 속성: `adm_cd` (8자리 행정동 코드), `adm_nm` (동 이름)

### 코드 매핑
| 접두사 (5자리) | 의미 |
|---|---|
| `11010` | 서울 종로구 |
| `11110` | 서울 중구 |
| `29140` | 광주 서구 |

### 전체 파일 분리 방법
34MB GeoJSON을 구별로 분리하는 Node.js 스크립트 사용:
```js
// adm_cd 앞 5자리 기준으로 그룹핑
const guCode = feature.properties.adm_cd.slice(0, 5);
// → public/geo/dong/11010.geojson 등 252개 파일 생성
```

## 4. VWorld API — WFS vs 2D Data API

### ❌ WFS API (`/req/wfs`)
```
https://api.vworld.kr/req/wfs?service=WFS&request=GetFeature&typeName=lt_c_ademd_info&key=KEY
```
- 인증키 오류가 발생할 수 있음
- `domain` 파라미터 미지원

### ✅ 2D Data API (`/req/data`) — 권장
```
https://api.vworld.kr/req/data?
  key=KEY
  &domain=http://localhost:5173
  &service=data
  &version=2.0
  &request=getfeature
  &format=json
  &data=LT_C_ADEMD_INFO          ← 행정동
  &attrfilter=emd_cd:like:11010  ← 구 코드로 필터
  &geometry=true
  &crs=EPSG:4326
```

### 데이터 타입
| data 값 | 설명 | 속성 |
|---|---|---|
| `LT_C_ADSIDO_INFO` | 시도 | `ctprvn_cd`, `ctp_kor_nm` |
| `LT_C_ADSIGG_INFO` | 시군구 | `sig_cd`, `sig_kor_nm` |
| `LT_C_ADEMD_INFO` | 읍면동 | `emd_cd`, `emd_kor_nm` |

### 참고
- [VWorld 2D Data API 샘플](https://github.com/V-world/V-world_API_sample)
- `domain` 파라미터에 요청 도메인 필수

## 5. 부동산 실거래가 API (data.go.kr)

### 엔드포인트
| API | URL |
|---|---|
| 아파트 매매 | `https://apis.data.go.kr/1613000/RTMSDataSvcAptTrade/getRTMSDataSvcAptTrade` |
| 아파트 전월세 | `https://apis.data.go.kr/1613000/RTMSDataSvcAptRent/getRTMSDataSvcAptRent` |

### 파라미터
| 파라미터 | 설명 | 예시 |
|---|---|---|
| `serviceKey` | 인증키 | (Encoding/Decoding 구분 주의) |
| `LAWD_CD` | 법정동 5자리 | `11110` (서울 종로구) |
| `DEAL_YMD` | 계약년월 | `202601` |

### 응답 형식
XML 형식으로 반환 → 파싱 필요

### CORS 해결
Vite proxy 설정:
```ts
// vite.config.ts
server: {
  proxy: {
    '/api/realestate': {
      target: 'https://apis.data.go.kr',
      changeOrigin: true,
      rewrite: (path) => path.replace(/^\/api\/realestate/, ''),
    },
  },
}
```
