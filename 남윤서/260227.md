# 260227 학습 회고록

## 1) LLM 기반 Pseudo Labeling (Knowledge Distillation)
- Upstage Solar API를 설정하고 데이터셋을 불러온 뒤, 프롬프트 엔지니어링으로 라벨 생성을 유도했다.
- 정답이 없는 데이터에 Teacher 모델의 생성 결과를 pseudo label로 붙여 Student 학습용 데이터를 만들었다.
- uv 기반 환경 구성과 노트북 실행 흐름을 익혔다.

## 2) Text-to-SQL LoRA 파인튜닝
- 데이터셋 로드와 EDA를 수행하고, Text-to-SQL 학습용 전처리 전략을 구성했다.
- base 모델/토크나이저를 불러와 LoRA(PEFT)로 파인튜닝을 진행했다.
- `inference.py`로 추론 결과를 만들고, `test-suite-sql-eval`로 execution accuracy를 평가했다.

## 3) QLoRA (4-bit 양자화)
- bitsandbytes로 4-bit 양자화된 base 모델을 로드했다.
- 4-bit 상태에서 LoRA 파인튜닝을 수행해 메모리 절감과 성능 유지의 균형을 확인했다.
- 동일한 평가 파이프라인으로 성능 변화를 점검했다.

## 4) vLLM & PagedAttention 추론
- PagedAttention과 KV Cache의 메모리 효율화 원리를 시뮬레이터/노트북으로 확인했다.
- vLLM에서 Runtime LoRA와 Merged 모델 방식의 차이를 비교했다.
- Transformers 대비 vLLM의 속도/처리량/메모리 지표를 벤치마킹했다.
- Text-to-SQL 추론 시스템 구성 흐름을 정리했다.
