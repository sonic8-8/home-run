## 1. Interface vs Type

### Interface

인터페이스는 객체의 구조(shape)를 정의하는 데 주로 사용됩니다.

```typescript
interface User {
  id: number;
  name: string;
  email?: string; // 선택적 프로퍼티
}

// 확장(extends)
interface Admin extends User {
  role: string;
}
```

**특징**
- `extends`로 확장 가능
- **선언 병합(Declaration Merging)** 지원 → 같은 이름으로 여러 번 선언하면 자동으로 합쳐짐
- 주로 객체 타입 정의에 사용

```typescript
// 선언 병합 예시
interface User {
  id: number;
}
interface User {
  name: string;
}
// 결과: { id: number; name: string; }
```

---

### Type

`type`은 인터페이스보다 더 넓은 범위의 타입을 정의할 수 있습니다.

```typescript
type ID = string | number; // 유니온 타입
type Point = { x: number; y: number }; // 객체 타입
type StringOrNumber = string | number;

// 교차 타입(Intersection)
type AdminUser = User & { role: string };
```

**특징**
- 유니온(`|`), 교차(`&`), 튜플 등 다양한 타입 표현 가능
- 선언 병합 불가 (같은 이름으로 재선언 시 오류)
- 프리미티브, 유니온, 튜플 타입 정의에 적합

---

### Interface vs Type 비교

| 구분 | Interface | Type |
|------|-----------|------|
| 객체 타입 정의 | ✅ | ✅ |
| 유니온 / 교차 타입 | ❌ | ✅ |
| 선언 병합 | ✅ | ❌ |
| `extends` 확장 | ✅ | `&`로 가능 |
| 클래스 `implements` | ✅ | ✅ |

> **가이드라인**: 객체/클래스 구조 정의에는 `interface`, 유니온이나 복잡한 타입 조합에는 `type`을 사용하는 것이 일반적입니다.

## 2. 클래스 (Class)

TypeScript의 클래스는 ES6 클래스에 타입 기능이 더해진 형태입니다.

### 기본 문법

```typescript
class Animal {
  name: string;

  constructor(name: string) {
    this.name = name;
  }

  speak(): void {
    console.log(`${this.name}이 소리를 냅니다.`);
  }
}

const dog = new Animal("강아지");
dog.speak(); // 강아지이 소리를 냅니다.
```

---

### 접근 제어자 (Access Modifiers)

| 제어자 | 설명 |
|--------|------|
| `public` | 어디서나 접근 가능 (기본값) |
| `private` | 클래스 내부에서만 접근 가능 |
| `protected` | 클래스 및 하위 클래스에서 접근 가능 |
| `readonly` | 읽기 전용 |

```typescript
class Person {
  public name: string;
  private age: number;
  protected email: string;
  readonly id: number;

  constructor(name: string, age: number, email: string, id: number) {
    this.name = name;
    this.age = age;
    this.email = email;
    this.id = id;
  }
}
```

**생성자 매개변수 단축 선언**

```typescript
class Person {
  constructor(
    public name: string,
    private age: number
  ) {}
}
// 위 코드는 프로퍼티 선언 + 할당을 동시에 처리
```

---

### 상속 (Inheritance)

```typescript
class Animal {
  constructor(public name: string) {}

  move(): void {
    console.log(`${this.name}이 이동합니다.`);
  }
}

class Dog extends Animal {
  bark(): void {
    console.log("멍멍!");
  }

  // 메서드 오버라이딩
  move(): void {
    console.log(`${this.name}이 뛰어갑니다.`);
  }
}
```

---

### Interface 구현 (implements)

```typescript
interface Flyable {
  fly(): void;
}

class Bird extends Animal implements Flyable {
  fly(): void {
    console.log(`${this.name}이 날아갑니다.`);
  }
}
```

---

### 추상 클래스 (Abstract Class)

직접 인스턴스화할 수 없고, 반드시 상속받아 사용해야 합니다.

```typescript
abstract class Shape {
  abstract getArea(): number; // 하위 클래스에서 반드시 구현

  describe(): void {
    console.log(`넓이: ${this.getArea()}`);
  }
}

class Circle extends Shape {
  constructor(private radius: number) {
    super();
  }

  getArea(): number {
    return Math.PI * this.radius ** 2;
  }
}
```

## 3. 제네릭 (Generics)

제네릭은 타입을 **매개변수화**하여 재사용 가능한 컴포넌트를 만드는 기능입니다.

### 기본 문법

```typescript
function identity<T>(arg: T): T {
  return arg;
}

identity<string>("hello"); // "hello"
identity<number>(42);      // 42
identity("world");         // 타입 추론으로 T = string
```

---

### 제네릭 인터페이스 & 타입

```typescript
interface ApiResponse<T> {
  data: T;
  status: number;
  message: string;
}

type Pair<T, U> = {
  first: T;
  second: U;
};

const response: ApiResponse<User[]> = {
  data: [...],
  status: 200,
  message: "success"
};
```

---

### 제네릭 클래스

```typescript
class Stack<T> {
  private items: T[] = [];

  push(item: T): void {
    this.items.push(item);
  }

  pop(): T | undefined {
    return this.items.pop();
  }

  peek(): T | undefined {
    return this.items[this.items.length - 1];
  }
}

const numberStack = new Stack<number>();
numberStack.push(1);
numberStack.push(2);
console.log(numberStack.pop()); // 2
```

---

### 제네릭 제약 (Constraints)

`extends`를 사용하여 제네릭 타입의 범위를 제한할 수 있습니다.

```typescript
interface HasLength {
  length: number;
}

function logLength<T extends HasLength>(arg: T): T {
  console.log(arg.length);
  return arg;
}

logLength("hello");       // 5
logLength([1, 2, 3]);     // 3
logLength({ length: 10 }); // 10
// logLength(42);         // ❌ 오류: number에는 length가 없음
```

---

### keyof와 제네릭

```typescript
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const user = { name: "Alice", age: 30 };
getProperty(user, "name"); // "Alice"
getProperty(user, "age");  // 30
// getProperty(user, "email"); // 오류
```

## 정리

| 개념 | 핵심 포인트 |
|------|------------|
| **Interface** | 객체 구조 정의, 선언 병합, 클래스 구현에 적합 |
| **Type** | 유니온/교차 등 복잡한 타입 표현에 적합 |
| **Class** | 접근 제어자, 상속, implements, abstract 클래스 |
| **Generic** | 타입을 매개변수화, 재사용 가능한 코드 작성, 제약(extends) 활용 |
